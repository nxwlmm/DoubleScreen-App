焦点即舞台（电视）

焦点卡片

上浮 6px + scale(1.04)，点缀色描边 + 3px 光环 + 35px 环境辉光；操作条随焦呈现于卡片正下方，OK 即主操作，不再跨屏换焦。

材质与动效

毛玻璃 blur(24px) saturate(180%)；1px 内高光 + 8% 白细线 + 4% 胶片噪点；缓动 cubic-bezier(.16,1,.3,1) 260ms；触控目标 ≥ 44px；尊重「减弱动态效果」。

无痕主题映射

只替换点缀色轴三元组 --accent-rgb（0,242,254 → 168,85,247）及其派生 --accent-blue / --stroke-glow / --on-accent；底色、表面层级、文字灰阶一律不动。切轴时扫描光掠过 + 全站 260ms 过渡。

V3.1 变更记录

  1. ① TV 局域网极速投源：电视端「新增配置」不再弹任何文本输入框，改为「局域网极速投源面板」——像素风二维码卡 + 本机服务地址 192.168.1.108:9978 + 三步引导；面板内提供「模拟手机已推送」演示按钮，走完接收→校验→入列的真实闭环。
  2. ② 无痕模式主题联动：手机端顶栏（加号左侧）新增护目镜胶囊开关，TV 端顶栏新增状态指示；切换后全站点缀色由电光青无缝过渡为极光紫，Toast 提示「无痕模式已开启：播放历史将不被记录」。
  3. ③ Ping 延迟语义：TV 与手机卡片的状态标签旁新增测速延迟标签（信号条 + 数值），三档语义：<80ms 极速 / 80–199ms 良好 / ≥200ms 较慢，失效源显示灰色「超时」。
  4. 卡片溢出（P0）：电视端卡片区改为单行横向轨道，焦点卡自动滚入视野，两端渐隐 + 页码指示（如 4 / 7）。配置再多也不会撑破容器。
  5. 空状态焦点断裂（P0）：无配置时焦点直接落在「新增配置」上，其余动作置灰禁用，按 OK 即进入投源面板——不再出现「按 OK 打开操作条」却无处落焦的死循环。
  6. 滑动误触（P0）：吸附阈值 62→72px；三个动作按钮加 3px 间隙、按「高频可逆 → 低频不可逆」左近右远排列；「设为当前」切换后浮出可撤销提示（1.9s 内可回退），消除静默改动全站内容的风险。
