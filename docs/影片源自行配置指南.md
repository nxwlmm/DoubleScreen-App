# 影片源自行配置指南

> 适用：本双端影视应用（电视 leanback 版 / 手机 mobile 版）
> 设计底线：应用不内置任何影片源。配置能力完整内置，内容来源由你自行添加与管理。

## 一、为什么是「自行配置」而不是「内置」

- 接入未授权影视聚合源的配置属于盗版分发链条，内置即构成分发工具，有实际法律风险（剑网行动历年专项打击对象）。
- 参考的 FongMi/TV、Box 官方版本均坚持「App 不内置任何内容来源」，用户自行配置——本应用采用同一策略。
- 自行配置的实际体验差异只有一步：第一次使用时粘贴一个链接，之后与内置无异。

## 二、支持的配置格式（解析内核全支持）

| 类型 | 格式 | 说明 |
|---|---|---|
| 单仓 | JSON（含 `sites` / `spider` / `lives` 字段） | 点播 + 直播一体配置 |
| 多仓 | JSON（`storeHouse` / `urls` 索引） | 一个链接管理多个单仓，可在界面里切换 |
| 直播 | M3U / TXT | 频道分组、台标（tvg-logo）、IPv6 标记均解析 |
| EPG | XMLTV | 节目单，与直播频道自动匹配 |

## 三、添加配置（首次约 1 分钟）

**手机端**：设置 → 源配置管理 → 点右下角「+」→ 粘贴你的配置链接（或点「扫码添加」扫描配置页二维码）→ 选择类型 → 确认添加 → 等待校验通过。

**电视端**：设置 → 源配置管理 → 焦点移到「新增配置」按 OK → 用遥控器输入或从手机推送链接 → 确认 → 校验通过即可。

提示：复制链接后打开添加页，会自动检测剪贴板并填充。

## 四、查看 / 更新 / 更换

- **查看**：设置 → 源配置管理，列表展示每个配置的名称、类型（单仓/多仓/直播）、状态（可用/失效/校验中）、最近更新时间；当前使用的源有「当前」标记。
- **更新**：对某个配置执行「检测更新」，应用重新拉取并校验，成功后刷新时间。
- **更换**：把新配置「设为当前」即可，全站影片/直播数据即时切换；旧配置保留在列表中随时切回。
- **删除**：需二次确认，防误删。
- **无痕模式**：开启后不记录播放历史，适合临时试源。

## 五、源失效了怎么办

聚合类配置链接失效是常态。处理方式：在源配置管理中删除失效项 → 添加新的配置链接即可。应用不依赖任何固定源，因此永远可以通过换链接恢复可用。

## 六、合规提醒

请自行确保所接入的内容来源合法（例如自己搭建的服务、公开授权的 IPTV 源、官方开放接口）。应用侧保持内容中立，使用责任在使用者。
